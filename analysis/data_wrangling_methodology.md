# Data Wrangling Methodology

GitHub URL: https://github.com/SaadAhmad00/SpaceX_Capstone_Coursera/blob/main/analysis/data_wrangling_methodology.md

Main wrangling steps:
1. Remove duplicate rows and irrelevant columns.
2. Standardize column names and data types.
3. Handle missing values with project-consistent imputations.
4. Normalize categorical labels (site/orbit/booster text cleanup).
5. Engineer `Class` and `Year` features.
